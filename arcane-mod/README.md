# Arcane Staff — мод для Minecraft 1.21.4 (Fabric)

## Что делает мод
- **Волшебный посох** с 4 заклинаниями: Огненный луч, Молния, Телепорт, Исцеление.
  - ПКМ — применить заклинание, Shift + ПКМ — переключить заклинание.
- **Два новых моба**: Кристальный голем (40 HP, сильный удар) и Арканный скелет (быстрый лучник). Не горят на солнце, роняют **Арканный кристалл**.
- **RPG-прокачка (как в Skyrim)**: за убийство монстров даётся опыт магии → уровни → очки навыков.
  Меню навыков — клавиша **K**:
  - Сила магии (до 5 рангов): +25% урона и лечения за ранг;
  - Быстрая магия (до 3 рангов): -15% перезарядки за ранг;
  - открытие заклинаний: Молния (с 2 ур.), Телепорт (с 3 ур.), Исцеление (с 4 ур.).
- Прокачка сохраняется в мире и не пропадает после смерти.

## Как получить предметы
- Крафт посоха: 3 Арканных кристалла + 2 палки (схема: `CC_ / CS_ / S__`, C — кристалл, S — палка).
- Команды (работают без читов):
  - `/arcane staff` — выдать посох;
  - `/arcane xp 100` — добавить опыт магии (для показа прокачки);
  - `/arcane reset` — сбросить прокачку.
- Яйца призыва мобов — в творческом режиме, вкладка «Яйца призыва».

## Что нужно, чтобы запустить в игре
1. Minecraft Java **1.21.4**.
2. Fabric Loader для 1.21.4 (https://fabricmc.net/use/installer/).
3. Fabric API для 1.21.4 (Modrinth или CurseForge) — положить в папку `mods`.
4. Файл мода `arcane-staff-1.0.0.jar` — тоже в папку `mods`.

## Как собрать мод (получить .jar)
### Вариант 1. Через GitHub, ничего не устанавливая
1. Создайте репозиторий на github.com и загрузите в него все файлы этого проекта (Add file → Upload files). Папка `.github` должна загрузиться вместе с остальными.
2. Откройте вкладку **Actions** → запустится сборка `build` (или нажмите Run workflow).
3. Через 3–5 минут откройте завершённую сборку и скачайте **Artifacts → arcane-staff-mod**. Внутри будет `arcane-staff-1.0.0.jar`.

### Вариант 2. На своём компьютере
1. Установите Java 21 (например, Temurin 21).
2. В папке проекта выполните: `gradlew build` (Windows: `gradlew.bat build`).
3. Готовый файл: `build/libs/arcane-staff-1.0.0.jar` (файл с `-sources` в конце не нужен).

## Сценарий показа преподавателю (2–3 минуты)
1. Создать мир в творческом режиме, выполнить `/arcane staff`.
2. Показать посох: ПКМ — огненный луч по мобу.
3. Вкладка «Яйца призыва» → призвать Кристального голема и Арканного скелета, победить их посохом.
4. Нажать **K** → показать древо навыков; `/arcane xp 200` → открыть Молнию и Телепорт, повысить Силу магии.
5. Shift + ПКМ — переключить заклинание, показать молнию и телепорт.

## Структура кода
- `arcane/item/` — посох и заклинания; `arcane/entity/` — мобы; `arcane/data/` — прокачка и сохранение;
- `arcane/net/` — обмен данными клиент ↔ сервер; `arcane/client/` — окно навыков и отрисовка мобов;
- `src/main/resources/` — тексты (ru/en), модели, текстуры, рецепт, добыча с мобов.
